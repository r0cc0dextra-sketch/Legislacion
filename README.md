# 🏛️ La OIT: Defendiendo los Derechos Laborales

Una página web educativa e interactiva sobre la Organización Internacional del Trabajo (OIT) con múltiples juegos para aprender sobre los derechos laborales.

## 📁 Estructura del Proyecto

```
/
├── index.html          # Página principal
├── styles.css          # Estilos CSS
├── script.js           # JavaScript con todos los juegos
└── README.md           # Este archivo
```

## 🚀 Cómo Usar

1. **Abre el archivo `index.html`** en cualquier navegador web moderno
2. **Navega** usando el menú superior o desplazándote por las secciones
3. **Juega** los diferentes juegos interactivos en la sección "Juegos Interactivos"
4. **Aprende** sobre la OIT de manera divertida y educativa

## 🎮 Juegos Incluidos

### 1. 🎯 Arrastrar y Soltar
- **Objetivo**: Empareja derechos laborales con sus descripciones
- **Puntuación máxima**: 80 puntos
- **Dificultad**: Fácil

### 2. 🧠 Juego de Memoria
- **Objetivo**: Encuentra las parejas de cartas relacionadas con la OIT
- **Puntuación máxima**: 100 puntos
- **Dificultad**: Media

### 3. 🔍 Sopa de Letras
- **Objetivo**: Encuentra 8 palabras relacionadas con la OIT
- **Puntuación máxima**: 150 puntos
- **Dificultad**: Media

### 4. ⏰ Línea de Tiempo
- **Objetivo**: Ordena cronológicamente los eventos históricos de la OIT
- **Puntuación máxima**: 120 puntos
- **Dificultad**: Media

### 5. ✅ Verdadero/Falso
- **Objetivo**: Responde 10 preguntas sobre la OIT
- **Puntuación máxima**: 100 puntos
- **Dificultad**: Fácil

### 6. 🖼️ Emparejar Imágenes
- **Objetivo**: Conecta iconos con convenios de la OIT
- **Puntuación máxima**: 130 puntos
- **Dificultad**: Media
